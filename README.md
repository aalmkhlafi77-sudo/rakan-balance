# RAKAN BALANCE — دفتر الحسابات الشخصي

تطبيق لإدارة الحسابات والحركات المالية وفق «لك / عليك / الرصيد»، بواجهة React وTypeScript وVite، وخادم Express وميزات للنسخ الاحتياطي والاختبارات.

## الوظائف والبنية

- إدارة الحسابات والحركات المالية وكشوف الحساب.
- واجهة ويب متجاوبة.
- طبقات تخزين وخادم ونسخ احتياطي وفق ملفات المشروع.
- اختبارات منطقية واختبارات واجهة Playwright.

## التشغيل المحلي

```bash
npm ci
npm run dev
```

## التحقق والبناء

```bash
npm test
npm run lint
npm run build
```

> يتطلب تشغيل الخادم الإنتاجي إعداد متغيرات البيئة وقاعدة البيانات المناسبة. لا ترفع ملفات البيئة الحقيقية أو أسرار المالك إلى GitHub. هذا الملف يصف البنية المتاحة ولا يضمن اكتمال جميع الميزات أو نجاح النشر.
